# EAFC27 JEBAT

A premium football esports dashboard for squad analysis, tactical coaching, and AI-powered football planning.

## Features
- Night stadium dashboard UI
- Signup/login mock flow
- Squad upload and AI-style assessment screen
- JEBAT chat assistant experience
- Formation advisor and visual tactical pitch
- Player recommendation cards
- Match analysis and saved squad history
- PWA setup with manifest and service worker

## Getting started

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Notes
This is a frontend prototype designed to be connected to a real Supabase and AI backend. Update `.env.example` with credentials before enabling external services.
